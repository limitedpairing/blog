This is the first post on **limitedpairing** — a single-page blog built with
[Jekyll](https://jekyllrb.com) and hosted on GitHub Pages.

## Why a single page?

A single page keeps things simple: the home page lists every post, and each
post gets its own permalink. No clutter, no heavy framework — just writing.

## Writing a new post

Drop a Markdown file in the `_posts/` directory, named like
`YYYY-MM-DD-title.md`, with this front matter at the top:

```yaml
---
layout: post
title: "Your title here"
date: 2026-06-10 09:00:00 +0000
tags: [example]
---
```

Then write your content in Markdown below it. That's it — the post will appear
on the home page automatically.

> Tip: run `bundle exec jekyll serve` locally to preview before pushing.

Happy writing.
